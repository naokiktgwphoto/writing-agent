# 選手特集（インタビュー）パイプライン

## インプット

- インタビュー文字起こし（または音声）
- 選手プロフィール（年齢・所属・ポジション・経歴）
- 媒体名・想定文字数・連載か単発か

## 媒体別フォーマット

### Number Web（松澤寛政・吉川大紀など）

**タイトル形式（クリック誘発・好奇心ギャップ型）**

Number Web のタイトルは「説明」ではなく「引き」。descriptive な仮題では通らない。編集部の実際の付け直し（吉川大紀連載, 2026）から抽出：

- 冒頭に**言いよどみ（…）付きの引用**を置く。
  - 例：「これ以上はどうにも…」／「母と2人、レンタカーで1カ月間全米を回って…」／「身体を鍛え上げただけでは…」
- **具体的な数字・実績を「…」で畳みかける**。
  - 例：母はビーチバレー日本女王、兄はトライアスロン、妹はレスリングで全米制覇…
- **謎かけ・問いで締める**。例：「〜のワケは？」「意外なワケ」「〜できるだろうか？」
- 主役に**覚えやすいラベル**を与え、タイトル・本文・結びで反復する。例：「（超）サラブレッド」
- キーワードは `""` でくくる。例：`"本場の壁"` `"名門大を中退"` `"兄妹は全米王者"`
- 従来型（「引用キーフレーズ」＋解説）も可。例：「なんとかなるよ」レイダースとドラフト外契約、"日本人初"の手前で松澤寛政が見ているもの
- 連載では各回タイトルにも共通テーマ（問い）を織り込む。

**連載の共通フック（各回の冒頭に置く）**

連載は全回を一つのセンセーショナルな「問い／謎」で貫く。単なる時系列評伝にしない。各回の冒頭に同一の“掴み”ブロックを置く：

1. 時事フック（例：松澤寛政の NFL 契約）
2. 中心の問い（例：「なぜこれまで日本人 NFL 選手は誕生しなかったのか」）
3. 「ある日本人選手が語ったその理由とは？」的な引き
4. `《NumberWebインタビュー全◯回の△回目／つづきを読む（最初から読む）》` のナビ

- 主役は「問いに答えるための入口」として提示する。

**構成（掴み優先 → 時系列）**

- 冒頭は生い立ちの時系列からではなく、**最も“映える”事実（血統・実績）＋中心の緊張（例「1.5軍、これ以上はどうにも…」）**を先に出す。
- そこから `◆`（または `◇　◇`）で場面・時制を転換し、時系列へ遡る。
- 著者が観察者として地の文に入る。
  - 例：「その落差を『ちょっと』と言えることが、この男の強さだ」
  - 例：「話術ではなく、思考の構造そのものなのだ」
- descriptive な中見出しを盛らない（オンライン連載は掴みブロック＋`◆` 区切りで流す。中見出しは CMS 側で付く前提）。

**一般読者への配慮（Number Web は専門外の読者も多い）**

- 専門用語・略語には **`（※やさしい説明）`** を付す。
  - 例：グレード6（※米国で主に11〜12歳が通うクラス）／ウォークオン（※奨学金のない一般枠での入学）／ギャップ（※ボールキャリアーが走ってくるコース）／グラデュエイト・トランスファー（※学部卒業後、残る出場資格を使うため別大学の大学院でプレーを続ける制度）／アサイメント（※戦術上の役割）
- **略称はスペルアウトする**。例：UTRGV 戦 → テキサス大学リオグランデバレー校戦。
- ポジション・プレーに一言説明を添える。例：QB サック → 守備の花形プレーである QB サック。

**削る・締める（過剰を落とす）**

- 本筋に効かない挿話・過度に細かい列挙・内輪ジャーゴンは削る（例：元同僚の近況の余談、母の旧姓の一致といった細部、FBS/FCS の細分、州名の全列挙は「……等々」に丸める）。
- 細切れの引用は1つに統合してテンポを出す。

**締め**

- 断定で閉じず、余韻・暗示で終わる。**タイトルのラベル（問い）を回収する問い**で締めると効く。
  - 例：「サラブレッドは、松澤に次ぐ新たな道を切り開くことはできるだろうか？」
  - 例：「それはもう手が届く距離かもしれない」

### 4years.（朝日新聞）

対象：学生アスリート・卒業直後の社会人1年目（廣田悠人、安藤謙太、東田隆太郎など）

**タイトル形式**

```
所属・ポジション・選手名　テーマ・キーワード「選手の言葉（引用）」
```

- **選手名・所属を必ず先頭に置く**（テーマから入らない）。
- 引用は末尾に置くか、名前の直後に置く（深掘り特集では名前直後が多い）。
- 例（引用末尾）：「日体大・齊藤進之助　未経験からTOP8の主力RBへ、バレー部出身の異色のキャリア」
- 例（引用末尾）：「京大WR廣田悠人、けがを越え取り戻した感覚「京大史上一番のWRに」」
- 例（引用末尾）：「東田隆太郎、関学から富士通へ「今はまだ10のうち4くらい」新人DBが見据えるもの」
- 例（引用中間）：「京都産業大主将・吉田碧海「自分には自分の人生がある」日本代表の父を持つ男が、アメフトで見つけた道」

**深掘り特集（父子・家族・転機など重層的なテーマ）の場合**

通常の選手プロフィール記事より踏み込んだ構成になる：

- `##` で章立てし、章タイトルにも引用を入れる。
  - 例：「「この4回生と勝ちたかった」3点差が残した傷と動機」
  - 例：「日本代表の父は「ラグビーをやれ」と言わなかった」
- 著者自身が地の文に登場することがある。
  - 例：「取材を終え、グラウンドを出る前に足が止まった」
  - 例：「取材後、車で駅まで送ってもらいながら、明はこう話してくれた」
- 締めは情景描写・余韻型（4years.の標準の「具体的展望」より Number Web的な終わり方）。
- 家族・恩師など選手以外の人物を主要インタビュー対象にする。

**構成**
1. リード（1段落）：選手プロフィール + 今季/今試合の活躍 + テーマ設定 + キーフレーズ（選手の言葉）
2. 具体的なプレーシーンまたは直近の試合エピソードから入る。
3. 経歴・背景（出身・他競技からの転向・家族・きっかけなど）。
4. 成長過程・現状の課題（コーチや周辺人物のコメントを交える）。
5. 今季の位置づけ・チーム状況。
6. 締め：選手の目標・決意の言葉 + 著者の一文で包む。

**引用源**
- 選手本人（メイン）
- コーチ・監督（能力評価や指導方針）
- 家族・先輩・同期・OB（選手の人間性・背景の補強）
- 複数の引用源を組み合わせて立体的に描く。コーチや関係者の長めの引用も厭わない。

**コメントセクションの見出しパターン**
コメント量が多い場合、発言者ごとに `##` で独立させる：
```
## QB菊地「めちゃめちゃ緊張してたけど、始まったら楽しくなった」
## 菅原QBコーチ「思い切りの良いプレーが、祥最大の持ち味」
## 菅野HC「1年生とは思えないオフェンスコントロール」
```
見出しは `## 役職・氏名「キーフレーズ」` 形式。引用は整えすぎず、話し言葉のまま使う。

**写真キャプション（4years.）**
- `キャプション説明（撮影・北川直樹）` — 中点（・）区切り
- 記事先頭で一括クレジット：`（すべて撮影・北川直樹）`

**文体**
- 章立ての使い方は記事の深さによって使い分ける：
  - 通常の選手特集（3,000〜4,000字程度）：`##` で章区切りを使う。章タイトルは「説明的・テーマ要約型」（例：「本格大学デビュー、初めての大舞台」「関学ではなく、立命を選んだ理由」）
  - 深掘り特集（5,000字以上）：`##` で章区切り。章タイトルに引用を含ませる（例：「「この4回生と勝ちたかった」3点差が残した傷と動機」）
  - ゲームレポート寄りの選手特集：`**太字**` のみで小見出しを付ける（`##` なし）
- 引用は長めでも可。話し言葉のトーンをそのまま生かす。
- スタッツや試合経過を具体的に記述（ヤード数・クオーター・プレーの詳細）。
- 著者の観察・解釈を要所に差し込む（「〜と苦笑する」「〜が、その言葉の裏に〜があった」）。
- 写真が複数入る前提で、写真に対応する地の文を置く。
- 大学生試合の場合は、名前（学年、出身校）、高校生試合の場合は、名前（学年）

### 週刊プレイボーイ（松澤寛政など）

**タイトル形式**
```
【前編】引用フレーズまたはシーン描写。選手名・所属の説明
```
- `【前編】`/`【後編】` を冒頭に置く（前後編の2本立てが基本）。
- 選手名は中盤〜末尾に置く（先頭には置かない）。
- 煽り気味の表現を使うが誇張はしない。
  - 例：「NFLに一番近い日本人になるまで。ハワイ大キッカー・松澤寛政の規格外キャリア」
  - 例：「「外したのに、スタジアム中から拍手が」。ドラフト目前、"Tokyo Toe"松澤寛政が語るキッカーの孤独な仕事」

**構成**
1. リード（2〜3段落）：物語の「起点」となるシーンから入り、現在地のプロフィールを簡潔に置く。
2. 本文：`■` で小見出しを区切る（`##` や `##` は使わない）。
3. 末尾にプロフィールBOX（`〜〜〜` で区切り、氏名・生年月日・経歴を箇条書き的に記載）。

**文体**
- 読者がアメフトを知らない前提で書く。
  - 数字・用語を身近なものに置き換えて説明する。
  - 例：「30ヤードのFGは、野球で言えばイージーなフライのようなもの」
  - 例：「アメフトに詳しくない方のために補足しておくと、……」
- 読者に語りかける地の文を使う。
- Number Webより口語的・エンタメ寄りだが、事実の誇張はしない。
- 著者の解釈・分析を随所に入れる（「〜だからだろう」「〜を物語っている」）。

### BBM Sports（選手特集）

**タイトル形式**
```
テーマを表す一文──選手名、状況の説明
```
- 例：「キッカーの椅子は、ひとつ──松澤寛政、レイダースで挑む53人のロースター枠」
- `──`（ダッシュ）区切りは編集部が付加するスタイル。原稿では省いてよい。
- 選手名は中盤に置く。

**構成**
1. リード（1〜2段落）：現在地 + `【北川直樹】` バイライン。
2. 本文：`##` で章区切り。太字の小見出しを段落冒頭に置く記法も可（記事の深さによって使い分け）。
   - `##` 使用例：`## 指名漏れから契約へ　今感じる「桁違い」の基準`
   - 太字のみ例：`**ベテランと競い、ベテランに学ぶ**`
   - どちらでも内容が優先されるため、編集部の体裁に合わせる
3. 締め：事実ベースで余韻を持たせる一文。「◯◯の本当の勝負は、ここからだ」のような現在進行形で終わる。

**文体**
- 引用を多く使う。一問一答に近い密度。
- 著者の観察・解釈を要所に差し込む（「こう言い切れるのは〜からだろう」）。
- 読者がアメフト・競技をある程度知っている前提（週プレほど説明補足をしない）。
- 写真クレジットは `photo by 氏名/チーム名` 形式（表紙・本文冒頭）。
- 本文中の写真キャプションは `=撮影：北川直樹` 形式（BBM試合レポートと共通）。

**その他の媒体（Sportiva・BBMなど）**
- 同一題材は切り口・エピソードを各媒体で重複させない。

## 構造の組み立て方（共通）

### 1. 構造軸（テーマ）を一本決める
記事全体を貫く「問い」や「葛藤」を最初に設定する。
- 例：「1.5軍の壁」「経験ゼロからの逆算」「日本を離れる選択」

### 2. 冒頭の入り方
- 具体的なシーン・情景・感覚から入る（抽象的な紹介文から始めない）。
- 例：「飛行機で泣いたのは覚えている」「パスポートを握りしめていた」

### 3. 本文の展開

#### 連載形式（2〜3回）
- 各回に「転機」を一つ置く。
- 時系列で進めながら、核心のエピソードでドラマを作る。
- 中見出しは「出来事＋示唆」の形式。
  - 例：「王子スタジアム、決勝点を蹴った夜」「残り1席だった飛行機」

#### 引用の使い方
- 選手の言葉を短く引用し、その後に著者の解釈を入れる。
- 謙遜・逡巡と確信が同居する瞬間を書く（「謙遜さを挟みながらもそう言い切る」のような観察）。
- 引用は話し言葉のトーンを保つ。整えすぎない。

### 4. 媒体ごとの出し分け
同一取材で複数媒体に書く場合、切り口・エピソードを重複させない。
媒体ごとに使うエピソードを事前に割り振る。

## 禁止事項

- 「——」（em-dash）を使わない。
- 記事の冒頭でプロフィール紹介から入らない（シーンから始める）。
- 締めに「今後の活躍が期待される」などのAI的常套句を使わない。
- 曖昧な意味づけで段落を閉じない（具体的な事実・引用・観察で閉じる）。

## 出力前チェックリスト

- [ ] 構造軸（テーマ）が一本通っているか
- [ ] 冒頭はシーン・情景から入っているか
- [ ] 各引用の後に著者の解釈が入っているか
- [ ] 同一媒体内でエピソードが重複していないか
- [ ] 締め文がAI的常套句になっていないか
- [ ] 選手名の表記ルール（外国人＝初出フルネーム、日本人＝姓のみ）を守っているか
